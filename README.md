# aparat-shortcode-manager
افزونه وردپرس برای مدیریت ویدئوهای آپارات و ساخت شورت‌کد قابل استفاده در نوشته‌ها، برگه‌ها و توضیحات محصولات ووکامرس. با این افزونه می‌توانید کد اسکریپت یا لینک ویدئوی آپارات را وارد کنید، شورت‌کد اختصاصی بگیرید و بدون به‌هم‌ریختن صفحه، ویدئو را به‌صورت ریسپانسیو نمایش دهید.
