# Aparat Shortcode Manager

افزونه ساده وردپرس برای مدیریت ویدئوهای آپارات و ساخت شورت‌کد قابل استفاده در نوشته‌ها، برگه‌ها و توضیحات محصولات ووکامرس.

## توسعه دهنده

نیما شادمان

## کاربرد

با این افزونه می‌توانید کد اسکریپت آپارات، لینک ویدئو، iframe آپارات یا شناسه ویدئو را در پیشخوان وردپرس وارد کنید و برای هر ویدئو یک شورت‌کد بگیرید.

ویدئوها به‌صورت ریسپانسیو نمایش داده می‌شوند و برای استفاده داخل توضیحات محصولات ووکامرس مناسب هستند.

نمونه شورت‌کد:

```text
[aparat_video id="123456789"]
```

## روش نصب

1. پوشه `aparat-shortcode-manager` را داخل مسیر `wp-content/plugins` قرار دهید.
2. از پیشخوان وردپرس وارد بخش افزونه‌ها شوید.
3. افزونه `Aparat Shortcode Manager` را فعال کنید.
4. از منوی پیشخوان، بخش `ویدئوهای آپارات` را باز کنید.

## روش استفاده

1. وارد بخش `ویدئوهای آپارات` شوید.
2. عنوان ویدئو را وارد کنید.
3. کد اسکریپت آپارات یا لینک ویدئو را داخل کادر بگذارید.
4. روی دکمه `ساخت شورت‌کد` بزنید.
5. شورت‌کد ساخته‌شده را داخل توضیحات محصول یا نوشته قرار دهید.

## نکته مهم

شورت‌کد را داخل لیست‌ها یا تگ‌های باز HTML قرار ندهید. بهتر است آن را در یک خط جداگانه بین متن‌ها بگذارید.

درست:

```text
متن توضیحات محصول

[aparat_video id="123456789"]

ادامه توضیحات محصول
```
